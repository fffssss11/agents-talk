# 第一次协作

[返回首页](../README.md) · [完整使用说明](user-guide.md)

目标：用一个小任务验证报到、分工、交付、验收和人工介入。此文是操作示例，没有预先执行模型调用。

## 1. 打开面板

安装 Python 3.10+，解压源码后，在源码目录打开终端：

```sh
python hub.py doctor
python start.py
```

macOS/Linux 可使用 `python3`。浏览器访问 [本地面板](http://127.0.0.1:8765/)。运行期间保留终端；前台按 Ctrl+C 停止。Windows 后台入口及桌面快捷方式见首页。

## 2. 选择两个或三个窗口

在「管理协作实例」中设置主导与协同者。不使用的默认成员取消勾选。可以用两个不同客户端，也可以用三个 Codex 窗口分别负责主导、实现和验收。

同客户端的不同窗口必须有不同实例编号。名称和模型标注只用于辨认，真正的模型要在对应客户端选择。不要让两个窗口共用一个实例编号。

## 3. 安装并逐个接入

以下示例仅安装 Codex 的两个 skill，先看预览，再写入：

```sh
python scripts/install_skills.py --clients codex
python scripts/install_skills.py --clients codex --apply
```

回到面板，复制每个实例的「接入说明」，分别发到对应原生客户端窗口。按客户端自身方式刷新技能列表。看到真实报到及读取活动后再继续，文件安装成功不代表接入成功。

## 4. 发一个范围明确的任务

在主导窗口输入这段示例，并填入面板里真实的实例编号：

> 使用 agents-talk-plan。目标是在 workspace/ 中制作一个无需联网的单页待办清单。主导、实现、验收分别使用我提供的三个实例编号。要求新增、完成、删除和本地保存；不用外部依赖。请生成发给各实例的提示词，明确文件范围、交付物、验收方式与最终整合安排。先确认缺失信息，不得把任务分给未启用成员。

把输出提示词发给各窗口。规划 skill 负责生成提示词，接入与执行使用 `agents-talk`。具体读写命令和任务状态规则仅维护在 [PROTOCOL.md](../PROTOCOL.md)。

## 5. 检查一次完整交接

- 「全员对话」可见成员发布的共享消息。不会显示尚未发布的原生窗口内部内容。
- 「协作工作树」可见派发、执行、预定验收和整合依赖。完成提交之后还需要独立审查。
- 在面板发送一条人工要求，例如「兼容手机窄屏」，检查接收实例的确认回执。
- 最终检查实际文件和测试记录。Token 未上报时保留「未报告」，不要用文本估算充当实际用量。

若成员停止读取，在原窗口重新调用该实例的接入说明。面板不能保证自动唤醒已经结束的模型回合。

完成后通过面板结束协作，等待成员响应、释放文件占用，再停止服务。保留私人备份，向他人分享时只使用发布源码包。
