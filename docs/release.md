# 发布与验收

## 当前状态

`0.1.0-rc.2` 已建立私有预发布仓库 [fffssss11/agents-talk](https://github.com/fffssss11/agents-talk)，正在准备上传与远端验证。尚未转为公开，也没有授予开源许可证。许可证及公开署名待项目所有者确认后更新。

## 发布包内容

运行程序、界面、协议、skill 源、安装/诊断/打包入口、示例配置、测试和开发说明。运行时无需 pip 或 npm 安装。开发者浏览器测试使用锁定版本的 Playwright。

包内 `SOURCE-MANIFEST.json` 记录每个源码文件的 SHA-256，包外 `.zip.sha256` 记录压缩包校验值。时间戳固定，同一份文件内容生成确定性的归档；校验值用于检查完整性，不构成作者签名。

仅打包 `release-files.json` 中精确列出的文件，不遍历私人数据目录，不包含自己的运行现场或依赖目录。打包器不覆盖现有 ZIP，重新打包时指定新输出路径或先人工保留/处理旧包。

## 发布步骤

1. 确认许可证、版权署名、公开仓库归属，人工检查现有源码及资源权属。当前没有内置第三方模型 SDK；客户端名称不代表官方关联。
2. 核对 VERSION、package.json 与 package-lock.json 一致。
3. 运行后端测试、三套浏览器测试和 `python hub.py doctor`。在目标操作系统上验证；CI 工作流的存在不等于实际成功。
4. 更新发布说明中的实际结果和未验证事项，审查发布清单，运行 `python scripts/build_release.py --check`。
5. 运行 `python scripts/build_release.py`，在全新目录解压，使用普通用户运行 `python hub.py doctor` 与 `python start.py --no-open`。应得到零消息、零任务、未接入的默认实例。
6. 在隔离客户端 skill 目录中验证预览、安装、重复安装和卸载，不修改真实客户端资料；确认包里没有个人路径、会话、附件或密钥。
7. 人工核对源文件及校验值，再由有权限的人公开上传。不要上传使用中的项目目录、私人备份或测试环境。

许可证待选时可用 `--allow-unlicensed` 生成私人审阅包，检查清单与路径，但不能将其标成已经授权的开源发布。

## 验证范围

本版保留多实例、聚焦上下文、媒体路由、Token 去重、工作树、持续监听和并发文件锁回归。新增安装器归属与卸载保留、默认配置回退、只读诊断、来源防护、打包隐私排除和干净解压启动验证。

实际结果在完成本轮验证后记录于下方。以下事项必须与源码测试区分：

- 原生客户端中的技能发现、模型调用及图片/视频能力，需用户各自在真实客户端验证。
- Windows 桌面快捷方式使用 Windows 专用脚本；macOS/Linux 使用前台启动入口，不声明已具备桌面安装包。
- 提供 Windows/macOS/Linux 的 Python CI 矩阵与 Linux 浏览器 CI，远程运行结果待真实仓库执行确认。
- 无压力测试或安全审计认证，长历史每次状态读取仍会推导事件，当前按本机小团队场景使用。

## 上一候选版的本地验证

2026-09-12，在 Windows、Python 3.13.5、Node 24.18.0、Playwright 1.63.0 环境验证：

- `python -m unittest discover -s tests -v`：运行 82 项，81 项通过，1 项因本机无法创建符号链接而跳过。包含真实解压后的零消息/零任务启动、Windows 后台服务复用和 PID 不匹配时拒绝停止。
- `npm ci` 对应的 lockfile 已生成，实际执行 `npm install --ignore-scripts` 成功；运行代码不依赖这些开发包。
- `npx playwright install chromium`：下载过程出现 TLS 传输错误，未完成；没有关闭 TLS 校验。设置 `AGENTS_TALK_BROWSER` 指向本机 Chrome 后运行 `npm test`，三套浏览器回归全部通过，包括发送、人工控制、重连、窄屏、观察窗、实例与会话切换竞态。
- 两个 skill 源通过本地 skill frontmatter 验证；安装测试只写入隔离目标目录。原生客户端内实际发现和模型执行未在本轮验证。
- 空白面板截图来自独立临时目录，检查桌面及 390px 窄屏，无真实对话或横向溢出。
- Windows 人工终端状态入口使用隔离数据验证通过，不报告 agent 读取心跳。
- 精确源码清单检查通过；重复归档字节一致，每个源码和最终 ZIP 都有 SHA-256。打包保留许可证待选标记，候选包没有个人会话、附件、运行日志或本地配置。

该轮未执行远程 CI、macOS/Linux 实机测试、真实模型/API/媒体调用或第三方安全审计。升级前备份及本地测试诊断保留在私人运行现场，未加入发布包。
