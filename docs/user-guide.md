# 使用说明

[返回快速开始](../README.md) · [协作协议](../PROTOCOL.md)

## 功能与边界

- Pi 已退出可选名单，历史归属保留，不改记为 ZCode；历史任务与文件占用按协议处理。此次替换不会卸载 Pi 程序。新第四成员 ZCode 仍需按本次任务在面板启用。
- 任务使用 depends_on 管理依赖，前置任务审查通过后后续任务才可执行。任务文件占用绑定任务和最新版本，同一文件不能由冲突任务同时修改。读取、修改和审查的完整顺序见协议，不能阻止客户端绕过工具直接改文件。

- 持续读取使用 `listen`，正常超时返回成功和下一步动作；面板提醒尚未读取、读取过期或主动退出的成员，并提供原窗口恢复说明。Claude 安装版附会话级 Stop 提醒，需重新调用 skill 并绑定当前窗口。此机制不能保证已结束的客户端回合自行唤醒，具体边界见协议「接入与循环」。

- Token 面板按实例显示输入、输出和总量，可切换当前/全部会话及按客户端汇总。实际值依赖各实例上报本窗口调用的 usage，不能把同一客户端账户总量重复分摊给多个实例；模型标注不替代调用来源。未上报显示「未报告」，重报去重。看板文本估算单列，不代表实际消耗，不含图片/视频服务费用，格式见协议。
- 「参与实例」勾选本次使用的独立窗口，默认 Claude、Codex、Reasonix，默认 ZCode 不参与。新增实例明确登记后自动加入本次名单，但仍需在客户端接入。未参与实例不能接收新派工，取消参与不删除历史或释放仍在使用的文件。旧待办保留，可按现有流程转交。
- 「全局协作上下文」默认关闭：执行成员只读自己与主导成员的任务和相关信息；开启后可读全队任务成果。主导成员始终保留全队摘要，人工面板保留完整记录。设置按会话保存，下次读取生效，无法撤回客户端已读内容。「预览成员所见」可检查实际返回范围和字符数。
- 成员默认读取任务摘要，包含交付、验证、待解决问题和来源，无嵌套历史。支持增量版本、任务分页和按需查证；具体命令、摘要发布规则与上下文边界统一见协议。摘要能减少历史重复，但实际 token 使用量取决于客户端和模型。
- 页面每秒同步共享黑板消息。客户端内部尚未发布的内容不可见，需要连续展示时由成员分段发布讨论和进展。
- 消息区已加高，点「放大阅读」可在独立大窗口中阅读和发送，Esc 返回。「全员对话」展示各实例动态和所有已加载共享消息，不受主面板筛选影响；阅读历史时停止跟随，点「回到最新」恢复。窗口中的「提出要求」打开人工干预输入，仍需手动发送。
- 「协作工作树」按正式依赖分层显示原始派发者、当前执行者、预定及实际验收人、整合方式与交付记录，点击依赖编号可定位。任务仅出现一次，多前置通过编号关联，搜索不会删除依赖。旧记录缺失安排显示「未指定」，由主导按协议补充；此处为流程视图，不创建 Git worktree，也不扩大 agent 的上下文权限。服务断线显示暂存状态，恢复后自动更新，切换会话关闭观察窗。
- 界面写入按会话互斥，发送和上传绑定发起时的会话与草稿；切换后忽略过期响应。新建会话失败时可在原页面重试，同一请求编号去重；刷新页面后应先确认会话是否已创建，避免重新发起。
- 干预使用独立的人类身份并显示确认回执。暂停、恢复、结束产生控制消息，成员下次读取时响应。外部工具调用无法被面板即时中断。
- 媒体任务仅派给 Codex 或 Claude。成员需验证图片或视频工具、报告能力后认领。面板提供任务路由与展示，生成工具由各客户端提供。
- 附件每个最多 32 MB，每条最多 8 个，常见图片与 MP4/WebM 可预览，其他类型下载查看。图像编辑需要参考图片。导出包含消息及附件路径，不打包附件文件。
- 搜索针对已加载消息，可继续加载历史，页面上限 10000 条。JSON / Markdown 导出包含当前会话全部消息。
- 重启后历史、任务和控制状态保留。agent 客户端需重新接入，120 秒无心跳显示过期。

## 管理会话和实例

点击「管理协作实例」编辑默认实例，或新增同一客户端的独立窗口。填写名称、模型标注和职责，在「接入说明」复制本实例的提示词到指定客户端。每个窗口只使用自己的实例编号。主导、执行和验收可以使用同一客户端、同一模型，但需要不同窗口和实例。

每个看板会话保留自己的参与名单。关闭某个实例的参与状态不会删除历史、转交任务或解锁。更换主导也不会转移旧任务。工作树显示正式分配和验收记录，缺失元数据会标成未指定。

## 配置与数据

无需配置密钥。缺少本地 `config.json` 时使用 `config.example.json`；运行 `python hub.py init` 可生成可编辑配置，不覆盖已有文件。配置包含四类客户端、新会话默认主导、模式和参与名单，不能通过编辑默认客户端 ID 增加实例。额外实例请在面板登记。配置改动后重启服务，现有会话明确保存的设置优先。

默认状态位于项目目录。需要独立数据目录时：

```sh
python hub.py --data-dir ./local-data --config ./config.example.json serve
python hub.py --data-dir ./local-data --config ./config.example.json sessions
python scripts/install_skills.py --clients codex claude --data-dir ./local-data --config ./config.example.json --apply
```

全局参数必须放在子命令前。面板和所有客户端必须使用相同的绝对数据目录及配置；面板接入说明会包含准确命令前缀。安装版 skill 固定使用安装时选定的配置；使用默认模板安装后再生成本地配置，或改用其他配置/数据目录时，需重新安装并接入。也可以设置 `AGENTS_TALK_DATA`、`AGENTS_TALK_CONFIG` 环境变量；命令参数优先。相对路径按执行命令时的工作目录解析。自定义 `local-data/` 也应加入你自己的 Git 忽略规则。

业务写入范围仍是项目的 `workspace/`。`--data-dir` 只改变状态位置，不改变业务文件范围。不同数据目录之间不共享锁表，不要让它们同时操作同一个 workspace；需要完全独立项目时复制干净发布包到不同目录。

| 位置 | 内容 | 可公开 |
| --- | --- | --- |
| `hub.py`、`web/`、`scripts/`、`skills/` | 程序与可移植 skill 源 | 经发布清单审查后可分发 |
| `config.example.json` | 无个人信息的默认配置 | 可分发 |
| `config.json` | 个人本地配置 | 默认排除 |
| `board.jsonl` | 消息、任务和用量事件 | 否 |
| `.seen/`、`.presence/`、`.listeners/`、`.bindings/`、`.hub.lock` | 游标、读取时间、进程锁、原生绑定 | 否 |
| `uploads/`、`workspace/` | 附件和业务成果 | 默认排除 |
| `.runtime/`、`.backups/`、`scripts/python-path.txt` | 日志、备份、设备信息 | 否 |

## 停止、备份和升级

前台启动按 Ctrl+C 停止服务，关浏览器不会停止服务。Windows 快捷方式启动的后台服务可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/stop.ps1`，脚本核对服务、目录和进程身份，仅停止匹配的服务。停止服务不终止原生 agent 或独立 CLI 等待进程。

备份前让所有成员停止写入并退出监听，再停止网页服务。完整复制原项目及外置数据目录到私人备份位置，保留日志、附件及配置，不单独删锁来解决冲突。备份包含个人信息，不可用于源码发布。

升级前保留备份并完成静止状态。只更新发布包内的源码文件，不覆盖已有 `config.json`、状态、附件和业务目录。此版本兼容旧的四默认实例与历史 Pi 事件，不自动迁移业务内容。移动目录前释放所有文件占用，移动后重新安装 skill 并重新接入原生窗口；已有客户端绑定、历史绝对附件路径可能仍指向旧位置，保留旧备份供核查，不承诺透明重定位。

## 常见问题

- 找不到 Python：运行 `python --version`，要求 3.10+。Windows 也可使用 `py -3`，macOS/Linux 通常使用 `python3`。启动器不会代你下载软件。
- 端口已占用：使用 `python start.py --port 8766`；Windows 后台启动器支持 `-Port 8766`。不要终止无法确认归属的进程。
- skill 找不到：确认安装到当前客户端实际使用的目录，新开会话或按客户端提供的方式刷新。文件复制成功不能证明客户端已发现并执行。
- 原生窗口停止读取：重新调用本实例的接入说明。服务重启不会自动唤醒模型回合，Claude 的 Stop 提醒也有明确边界，见协议。
- 配置或日志报错：运行 `python hub.py doctor`。它只读，不修复或截断日志，保留现场。输出包含本地路径，公开提问前需脱敏。
- 页面断线：启动服务后页面会重连；确认状态和接收人再重试发送。失败结果不明确时先核对消息，避免重复操作。
- Token 未报告：需要客户端上报真实调用 usage；文本估算不能替代实际账单。
- 安装到其他目录：用 `--target CLIENT=SKILL_ROOT`，完整示例见 README。多个客户端不能共用同一安装目录。

排查 Windows 后台启动问题查看 `.runtime/launch-error.log` 与 `.runtime/server-error.log`。请勿把整份日志和会话历史直接上传到公开问题区。
