# 项目介绍材料

![项目介绍封面，AI 概念配图与可编辑标题](../assets/project-overview.png)

## 一句话介绍

Agents Talk 是连接独立 AI 客户端会话的本地协作面板，让任务分工、共享讨论、人工要求、独立验收和最终整合有记录可查。

## 可直接使用的短介绍

Agents Talk 支持 Codex、Claude Code、Reasonix、ZCode，也支持同一客户端的多个独立窗口承担不同角色。成员通过 skill 和本地共享事件协作，面板集中显示对话、任务工作树和真实上报的用量。Python 标准库即可运行，用户逐个接入原生窗口，无需为面板配置模型 API Key。

项目提供聚焦与全局摘要两种上下文范围、人工干预、任务文件占用、依赖和独立验收约束。图片或视频任务只能派给已验证相应能力的 Codex/Claude 实例。模型调用、客户端登录及媒体工具由各客户端提供。

适合在可信个人工作站上尝试多窗口协作。当前界面和详细协议以中文为主；不提供公网多租户权限、原生窗口自动创建或回合结束后的自动唤醒保证。

## 宣传材料边界

- 首页截图为独立空白会话，界面示例为隔离演示数据，未调用真实模型。
- 不引用虚构的用户数、星标数、执行速度、Token 节省比例或媒体生成效果。
- PPT 文字可编辑，界面截图保留实际界面。PDF 用于阅读展示。
- PPT 使用微软雅黑，接收端缺少字体时可能发生替换。PDF 为幻灯片图像阅读版，不依赖接收端字体。
- 封面为 AI 生成的概念配图，不代表真实产品界面。客户端名称只标识互操作对象，不代表官方关联或背书。
- 功能与限制以当前 [README](../../README.md)、[协议](../../PROTOCOL.md) 和 [安全边界](../../SECURITY.md) 为准。具体测试结果见 [发布说明](../release.md)。

## 建议演示顺序

启动空白面板，登记三个独立实例，逐个接入；发送小任务，观察工作树和共享消息；追加人工要求，检查回执；展示验收和最终整合记录。演示前清空或切换到独立数据目录，不使用正式聊天历史。

本版提供 6 页 PPTX、对应 PDF 阅读版和 54 秒 1080p/60fps MP4。视频使用平滑推拉、文字分步出现和转场，包含原创合成配乐，无旁白。

[下载全部材料](https://github.com/fffssss11/agents-talk/releases/tag/v0.1.0-rc.3)。动画源码、分镜及复现步骤见 [宣传视频](../promo/README.md)。大型二进制附件仅在 Release 分发。
